# Medical Stats Analyzer

Minimal instructions to set up and run the project locally.

Prerequisites
- Install Node.js 18.x (LTS) or 20.x and npm. On Windows, use the official installer from https://nodejs.org/.

Install and run
```bash
npm install
npm run dev
```

Notes
- The project uses Next.js (13.x) with the `app/` directory and React 18.
- If you see install errors, ensure your npm/node are on a recent LTS release.

If you'd like, I can also pin `lucide-react` to a specific version and run additional compatibility checks.
